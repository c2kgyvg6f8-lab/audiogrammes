    Mode d'emploi

    1. Choisir la source (une fois par séance) : de préférence la fenêtre du logiciel Doctolib ou d'audiométrie. La capture marche même quand cet outil est devant.
    2. Cliquez sur 📌 Au premier plan : les commandes passent dans une petite fenêtre qui reste au-dessus de Doctolib.
    3. Affichez un audiogramme, cliquez sur Capturer : il est lu et ajouté directement, sans validation. Tapez sa date dans la liste. ✎ permet de vérifier ou corriger un examen à tout moment.
    4. Cochez les courbes à afficher : aérienne, osseuse, vocale (une, deux ou les trois). L'aperçu se met à jour.
    5. Envoyer vers Doctolib crée le PDF et l'écrit dans le dossier d'import (passerelle) de Doctolib.
    Rouge = oreille droiteBleu = oreille gaucheVert = conduction osseuse
    Rien ne quitte votre ordinateur : la lecture et le PDF se font dans Chrome. La première fois, faites « Envoyer » depuis cet onglet pour que Chrome autorise le dossier Doctolib ; ensuite, la fenêtre flottante suffit.
