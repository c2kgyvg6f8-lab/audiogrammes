# Superposeur d'audiogrammes

Outil qui tourne dans Chrome : il lit les audiogrammes affichés à l'écran (Doctolib bureau ou web, logiciel d'audiométrie) ou glissés en PDF, récupère le patient et la date, superpose les courbes (aérienne, osseuse, vocale) dans un PDF et le dépose dans le dossier d'import (passerelle) de Doctolib.

Ouvrir : https://c2kgyvg6f8-lab.github.io/audiogrammes/

Tout le traitement se fait localement dans le navigateur : aucune image ni donnée patient n'est envoyée sur Internet.
